# آپدیت یکپارچهٔ واخان ۰٫۲٫۸ — نسخهٔ آزمایشی، ساخت ۲۲

این بسته فایل واقعی آیفون و نصب‌کنندهٔ یکپارچهٔ اندروید و سرور را دارد.
نصب روی سرور هنوز انجام نشده است. موفقیت کامپایل به معنی تأیید صدا روی گوشی نیست.

## ۱. ابتدا آپدیت سرور و اندروید

همین ZIP را با نام `Wakhan-Consolidated-0.2.8-beta.zip` در پوشهٔ `/root` سرور
واخان آپلود کن، سپس این دستور را اجرا کن:

```sh
python3 -m zipfile -e /root/Wakhan-Consolidated-0.2.8-beta.zip /root && python3 /root/wakhan-update-028.py
```

نصب‌کننده این کارها را انجام می‌دهد:

- سورس واقعیِ نسخهٔ بررسی‌شده و تغییر شناخته‌شدهٔ TURN/TLS را بررسی می‌کند.
- بک‌اند مستقل را ابتدا با کپی دیتابیس، نشست فعلی مدیر و پخش واقعی صدا/تصویر تست می‌کند.
- APK و AAB اندروید را در پوشه‌ای جدا می‌سازد و با کلید قبلی امضا و بررسی می‌کند.
- سپس سرویس برنامه را روی همان پورت قبلی جایگزین می‌کند؛ دیتابیس اصلی جابه‌جا نمی‌شود.
- قبل از باز شدن سرویس جدید، حفظ دفتر سکه‌ها و قابلیت‌های تازه را بررسی می‌کند.
- فقط دو حساب قدیمیِ تأییدشده را، اگر هنوز ورود مستقل ندارند، حذف می‌کند.
- آیدی عمومی هشت‌رقمی اختصاص می‌دهد؛ آیدی داخلیِ اطلاعات و سکه‌ها ثابت می‌ماند.
- مسیرهای UDP/TCP/TLS رله را روی خود سرور آزمایش و پورت‌های لازم UFW را باز می‌کند.
- اجرای تلگرام را بازنشسته و تنظیمات فعال آن را حذف می‌کند. نسخهٔ برگشت خصوصی
  و محیط مشترکِ موردنیاز مرورگر تأمین‌کننده حفظ می‌شوند. VPNهای قبلی خاموش می‌مانند.

اگر آزمون اولیه یا ساخت اندروید شکست بخورد، سرویس فعلی متوقف نمی‌شود. اگر هنگام
جایگزینی خطا رخ دهد، سرویس قبلی برگردانده می‌شود؛ دیتابیس قدیمی روی تراکنش تازه نوشته نمی‌شود.
اجرای دوباره، در صورت تکمیل موفق، وضعیت همان نصب را بررسی می‌کند.

فایل گزارش را بفرست:

```text
/root/wakhan-028-result.zip
```

خروجی‌های موفق اندروید:

```text
/root/Wakhan-0.2.8-beta-test.apk
/root/Wakhan-0.2.8-beta.aab
```

برنامهٔ نصب‌شدهٔ قبلی را پاک نکن؛ APK با امضای قبلی برای به‌روزرسانی روی آن ساخته می‌شود.
خروجی debug در GitHub فقط بررسی کامپایل است و جای APK امضاشدهٔ سرور را نمی‌گیرد.

## ۲. نصب آیفون با ویندوز

بعد از موفقیت گزارش سرور، ZIP را روی ویندوز باز کن. فایل
`Wakhan-0.2.8-beta.ipa` را به Sideloadly بده و مثل قبل با همان Apple ID و تنظیمات
Bundle ID نصب کن. این IPA را Xcode روی مک GitHub ساخته و محتوای واقعی آن بررسی شده است.
خود IPA امضای توزیع ندارد؛ Sideloadly آن را برای گوشی تو امضا می‌کند.
نصب رایگان معمولاً هفت روز اعتبار دارد. حساب Apple Developer پولی برای این تست لازم نیست.

## ۳. مواردی که داخل این آپدیت آمده

- اصلاح دو بار کوچک‌شدن صفحه هنگام بازشدن کیبورد اندروید.
- حفظ تب‌ها، اسکرول، پیش‌نویس‌ها و اجزای فعال رسانه هنگام جابه‌جایی.
- ریپلای واقعی در خصوصی، نمایش نقل‌قول و رفتن به پیام اصلی.
- پیش‌نمایش عکس و ویس، ارسال/لغو و تلاش مجدد بدون ارسال تکراری یا ارسال به چت دیگر.
- رفع محدودیت قدیمی ۶۴ کیلوبایتی آپلود و کنترل دسترسی فایل خصوصی.
- سالن فشرده‌تر با ده صندلی، وضعیت اتصال و کنترل میکروفون واضح‌تر.
- صف درخواست آهنگ، رأی، کنترل میزبان، علاقه‌مندی، فیلتر زبان/موضوع/دوستان/اخیر و رویداد سالن.
- بازی مشترک سبک حدس عدد؛ بدون شرط‌بندی و تغییر سکه.
- حالت سبک و کاهش جلوه‌ها، و یکسان‌سازی حروف فارسی/عربی در جست‌وجوی موزیک.
- تنظیم اعلان‌ها، ثبت دستگاه با انتخاب کاربر و بررسی گزارش کاربران برای مدیر.
- تشخیص مسیر صدا و انتخاب مسیر امن، با گزارش فنی بدون رمز و متن مکالمه.
- پخش بومی موزیک اندروید با Media3/ExoPlayer، کنترل اعلان و مدیریت فوکوس صدا.
  این پخش‌کننده فایل آهنگ را مستقل از رندر صفحه پخش می‌کند.
- تنظیم نشست صدای iOS برای ضبط خصوصی، قطع دستگاه صوتی و توقف کامل هنگام خروج از حساب.

## ۴. آزمون واقعی قبل از انتشار

روی A13 و آیفون، کیبورد را در سرچ موزیک، خصوصی، ریپلای و انتقال سکه باز و بسته کنید؛
برگشت بین تب‌ها باید متن و اسکرول را حفظ کند. عکس و ویس را در دو جهت بفرستید،
قطع اینترنت و تلاش مجدد را امتحان کنید و پیام تکراری بررسی شود.

موزیک را با اینترنت ثابت، هنگام رفتن به صفحهٔ اصلی گوشی و خاموش بودن صفحه حداقل
ده دقیقه تست کنید؛ توقف/ادامه از اعلان، قطع هدفون و تماس ورودی را هم بررسی کنید.
پخش HTML داخل مرورگر، تست میکروفون ساختگی و موفقیت کامپایل جای این آزمون را نمی‌گیرند.

صدای دوطرفهٔ سالن باید روی ایرانسل **بدون VPN** و با تغییر وای‌فای/دیتا تست شود.
باز شدن برنامه یا موفقیت رله روی خود سرور، دسترسی واقعی از ایران را ثابت نمی‌کند.
گزارش فعلی فقط صدای خوب با VPN فرانکفورت را تأیید کرده است.

## ۵. پیش از اپ‌استور و گوگل‌پلی

این بسته beta است. برای انتشار، حساب فروشگاه، حریم خصوصی و حذف حساب، مجوزهای رسانه،
گزارش و مسدودسازی کاربر، فرم‌های اطلاعات داده و امضای انتشار باید تکمیل شوند.
فروش سکه/اشتراک دیجیتال باید برای فروشگاه و کشور هدف، با خرید داخل برنامه و تأیید
سمت سرور سازگار شود؛ اتصال StoreKit/Google Play Billing در این نسخه پیاده نشده است.
اعلان iOS نیز به تنظیم APNs/Firebase و حساب مربوط نیاز دارد؛ در نصب رایگان خاموش است.

Google Play Console هزینهٔ ثبت‌نام یک‌باره دارد، نه اشتراک ماهانه. شرایط تست حساب
شخصی جدید را خود کنسول نشان می‌دهد و باید پیش از درخواست انتشار تکمیل شوند:
https://support.google.com/googleplay/android-developer/answer/6112435
https://support.google.com/googleplay/android-developer/answer/14151465

حساب معمولی Apple ID با عضویت پولی Apple Developer متفاوت است. ثبت‌نام انتشار:
https://developer.apple.com/programs/enroll/
قوانین بررسی اپ‌استور:
https://developer.apple.com/app-store/review/guidelines/

بنچمارک واقعی روی ضعیف‌ترین گوشی‌ها یا اندازه‌گیری سرعت رقبا انجام نشده است؛
برابری سرعت و بی‌باگ بودن کامل ادعا نمی‌شود.
