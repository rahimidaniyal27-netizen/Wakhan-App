# واخان ۰٫۲٫۹ — به‌روزرسانی آزمایشی

اول فایل ZIP را روی همان سرور قبلی، داخل پوشهٔ /root بگذار. سپس این دستور را یک بار اجرا کن:

```bash
python3 -m zipfile -e /root/Wakhan-Consolidated-0.2.9-beta.zip /root && python3 /root/wakhan-update-029.py
```

در پایان، فایل `/root/wakhan-029-result.zip` را به همین گفتگو بفرست.

این به‌روزرسانی برای سرویس مستقل ۰٫۲٫۸ است که قبلاً نصب کردی. فایل نصب قدیمی ۰٫۲٫۸ را دوباره اجرا نکن.

فایل اندروید روی سرور با همان کلید امضای قبلی ساخته می‌شود. قبل از تعویض سرویس، نسخهٔ جداگانهٔ سرور با کپی پایگاه داده بررسی و تصویر و صدای مسیر واقعی پخش سالن آزمایش می‌شود. اگر بررسی قبول نشود، نسخهٔ فعلی فعال می‌ماند. در تعویض موفق، حساب‌ها و پایگاه دادهٔ فعلی حفظ می‌شوند؛ برگشت اضطراری کد سرویس را برمی‌گرداند و پایگاه دادهٔ قدیمی روی انتقال‌های تازه جایگزین نمی‌شود.

پس از نتیجهٔ موفق، اندروید را از این لینک بگیر و برای دوستت بفرست:
https://music.kabulcafe.uk/download/Wakhan.apk?build=23

آیفون: فایل `Wakhan-0.2.9-beta.ipa` را در ویندوز داخل Sideloadly انتخاب و با همان Apple ID قبلی نصب کن. برنامهٔ قبلی را حذف نکن. امضای رایگان اپل معمولاً هفت‌روزه است.

تغییرهای این نسخه شامل صندلی‌های تکی قرمز بدون +، ظرفیت ۲ تا ۱۶، پس‌زمینهٔ دلخواه، چت شفاف هنگام تایپ، کنترل داخل پرده و پایان پخش، ریپلای با کشیدن پیام، خوانده‌شدن پیام و تنظیم نمایش آنلاین، اصلاح برگشت و فاصله از نوار وضعیت، راهنمای داخلی و مدیریت مستقل است.

ساخت موفق به معنی تأیید روی گوشی واقعی نیست. کیبورد سامسونگ و آیفون، صدای دوطرفه، پخش در پس‌زمینه و اتصال روی ایرانسل بدون VPN همچنان به آزمایش دستگاه نیاز دارند. اعلان آیفون در نصب رایگان و خرید درون برنامه‌ای فروشگاه فعال نیستند؛ این بسته نسخهٔ نهایی فروشگاه نیست.
