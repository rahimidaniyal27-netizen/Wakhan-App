# اصلاحات برنامهٔ واخان ۰٫۲٫۱۲

این بسته برای سرور فعال ۰٫۲٫۱۱ است و فایل نصب گوشی را به نسخهٔ ۰٫۲٫۱۲، بیلد ۲۶ ارتقا می‌دهد. سرور و دیتابیس به نسخهٔ دیگری منتقل نمی‌شوند.

اصلاحات: نام یکپارچهٔ «دنج» برای سالن‌های گفتگو، کادر پیام هماهنگ با حرکت کیبورد، چرخش فقط هنگام فیلم تمام‌صفحه، ریپلای روان‌تر و نمایش آخرین پیام هنگام برگشت، حذف انتخاب ناخواستهٔ متن رابط، انیمیشن آغازین اصلی با Live و بدون سایهٔ سنگین، تعویض پایدار فیلترهای سالن بدون چشمک عکس یا نتیجهٔ قبلی، نشانگر سبز متحرک سالن، عکس ساده در ویرایش پروفایل، یکسان بودن عکس سالن داخل و بیرون، چیدمان و فاصلهٔ کنترل‌های تمام‌صفحه، برگشت درست به اندازهٔ عادی، جای ثابتِ سربرگ پروفایل و نوار شیشه‌ای خواناتر پایین سالن.

ZIP را با نام `Wakhan-Consolidated-0.2.12-beta.zip` در `/root` سرور قرار بده و بزن:

```sh
python3 -m zipfile -e /root/Wakhan-Consolidated-0.2.12-beta.zip /root && python3 /root/wakhan-client-0212.py
```

اندروید با کلید قبلی ساخته و پس از بررسی در همان مسیر دانلود منتشر می‌شود. سرویس متوقف نمی‌شود؛ اسکریپت دیتابیس را تغییر نمی‌دهد. فایل قبلی اندروید برای برگشت نگه داشته می‌شود.

گزارش: `/root/wakhan-0212-result.zip` را بفرست.
