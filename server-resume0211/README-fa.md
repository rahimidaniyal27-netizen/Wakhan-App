# ادامهٔ نصب واخان ۰٫۲٫۱۱

اندروید آماده است. بررسی نهایی نصب به‌اشتباه نسخهٔ ۰٫۲٫۱۰ را انتظار داشت؛ این فایل فقط همان بررسی را اصلاح می‌کند. فایل‌های آیفون و اندروید قبلی تغییری نمی‌کنند و اندروید دوباره ساخته نمی‌شود.

ZIP را با نام `Wakhan-0211-Resume.zip` در `/root` سرور بگذار و بزن:

```sh
python3 -m zipfile -e /root/Wakhan-0211-Resume.zip /root && python3 /root/wakhan-resume-0211.py
```

فایل اصلی `/root/wakhan-update-0211.py` باید همان فایل نصب قبلی باقی بماند. ادامهٔ نصب، اعتبار همان فایل را بررسی می‌کند و آزمایش تصویر، صدا، حساب و حفظ سکه‌ها را دوباره انجام می‌دهد. هیچ بررسی حفاظتی حذف نمی‌شود.

بعد، فایل `/root/wakhan-0211-result.zip` را بفرست. آیفون همان فایل `Wakhan-0.2.11-beta.ipa` قبلی است. دانلود اندروید فقط پس از موفقیت نصب: `https://music.kabulcafe.uk/download/Wakhan.apk?build=25`.
