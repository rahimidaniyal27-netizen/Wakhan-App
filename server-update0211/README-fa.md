# به‌روزرسانی واخان ۰٫۲٫۱۱

این بسته برای نسخهٔ فعال ۰٫۲٫۱۰ است. حساب‌ها، پیام‌های خصوصی، سکه‌ها و کلید امضای اندروید حفظ می‌شوند. موسیقی و سینما رایگان می‌مانند. پیپال حذف شده است؛ پرداخت آنلاین تا راه‌اندازی حساب تجاری فعال نیست.

فایل `wakhan-update-0211.py` را در `/root` سرور قرار بده و این دستور را اجرا کن:

```sh
python3 /root/wakhan-update-0211.py
```

اسکریپت ابتدا اندروید را با کلید قبلی می‌سازد، نسخهٔ جداگانه را با دیتابیس کپی آزمایش می‌کند، تصویر و صدا و Range را بررسی می‌کند و سپس سرویس را جابه‌جا می‌کند. در صورت خطا، نسخهٔ فعال دست‌نخورده می‌ماند یا فقط کد سرویس برمی‌گردد؛ دیتابیس قدیمی برگردانده نمی‌شود.

گزارش: `/root/wakhan-0211-result.zip` را همین‌جا بفرست. پس از موفقیت، اندروید: `https://music.kabulcafe.uk/download/Wakhan.apk?build=25`. نسخهٔ آیفون داخل همین بسته، فایل `Wakhan-0.2.11-beta.ipa` است؛ با Sideloadly نصب کن. برنامهٔ قبلی را پاک نکن.

این نسخه هاله‌ها، پنجره‌های روی هم، چت سالن، جابه‌جایی جایگاه‌ها و نمایش عکس فهرست سالن‌ها را اصلاح می‌کند. نسخهٔ قبلی فعلاً برای برگشت محفوظ می‌ماند. پیام‌های سالن بعد از خروج و ورود دوباره برای همان فرد نمایش داده نمی‌شوند؛ تاریخچهٔ دیگر افراد داخل سالن حذف نمی‌شود.

آزمایش مرورگر جای آزمایش واقعی میکروفون روی آیفون و سامسونگ A13 را نمی‌گیرد. انتشار فروشگاهی و دریافت پول هنوز آماده نیست.
